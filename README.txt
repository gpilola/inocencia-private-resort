INOCENCIA PRIVATE RESORT WEBSITE

Files:
- index.html: website content and structure
- styles.css: responsive design and styling
- script.js: mobile menu, photo viewer, animations, and inquiry form
- assets/: logo and resort photos

HOW TO VIEW
Open index.html in a modern browser.

HOW TO PUBLISH
Upload the contents of this folder to your web hosting public directory. The site is static and works on services such as GitHub Pages, Netlify, Cloudflare Pages, cPanel hosting, or Azure Static Web Apps.

BOOKING FORM
The form uses mailto and opens the visitor's default email application. For database storage or automatic email delivery, connect the form to a backend or form service.

CUSTOMIZATION
Edit the text in index.html. Colors are defined at the top of styles.css. Replace image files in assets and update image paths in index.html if needed.
